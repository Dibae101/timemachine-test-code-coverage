Add 6 datasets from the llm-gui-testing-research app set: 19 apps passing

The private research repo is readable with the token in .env, and dataset/apps.tsv
is the useful part: 50 apps with package, min_sdk, target_sdk, and for 22 of them
the exact source_repo, source_ref and source_commit the tested APK was built from.
Exact refs remove the tag guessing that caused most earlier build failures.

19 of those apps were not already in the set and install on API 25. Money Manager
Ex was excluded: min_sdk 26 cannot install on an API 25 emulator. Eleven built,
and six now produce a clean coverage report:

    SkyTube             16.41%      Orgzly-Revived   14.63%
    LibreTorrent         9.37%      ownCloud          6.57%
    Infinity-For-Reddit  3.16%      Kore              1.72%

Total: 19 apps passing, up from 13.

Three build faults were fixed to get there, all in the tooling rather than the
apps:

  * Modern projects declare repositoriesMode = FAIL_ON_PROJECT_REPOS in
    settings.gradle, which makes adding a repository from an init script a build
    error. The init script now adds repositories at settings level through
    beforeSettings and relaxes the mode to PREFER_PROJECT.
  * The JDK fallback ladder retried Gradle 8 builds on JDK 8 and 11, which cannot
    work, wasted a build each, and buried the real error at the end of the log -
    GPSLogger's actual failure was masked that way. Retries are now gated by
    Gradle version.
  * Module detection missed two declaration styles: Jellyfin applies
    alias(libs.plugins.android.app) and Kiwix uses a bare `android` accessor from
    its own buildSrc convention plugin. There is now a fallback that looks for a
    module whose manifest declares an application with a launcher intent filter.
    Muzei exposed a ranking bug too: its example-unsplash sample module was picked
    over the real app, so sample and demo modules are now ranked last.

One side effect worth recording: building Kiwix installed its own pre-commit hook
into this repository's .git/hooks, which then failed every commit with
"./gradlew: not found". Cloned trees have their .git removed so they are stored as
files rather than gitlinks, which means a build task that installs git hooks
resolves to the parent repository instead. The foreign hook has been removed.

Still not passing, kept for a further pass: Fedilab, Jellyfin-Android, Kiwix,
Open-Food-Facts and Vinyl-Music-Player. Kiwix reports 15.52% standalone but
