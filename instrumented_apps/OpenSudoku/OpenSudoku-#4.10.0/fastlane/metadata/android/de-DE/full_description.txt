Open Sudoku ist ein Open Source Sudoku Spiel.

Features:
	• Ohne Werbung
	• Rätsel können aus dem Web heruntergeladen, von Hand eingegeben oder auf der Projektwebpage generiert werden
	• Spiel-Statistiken (Zeit, Fehler)
	• Vorschlag für den 'Nächster Schritt' unter Nutzung verschiedener Strategien
	• Import und Export von Rätseln aus einer bzw. in eine Datei
	• Visuelle Themen, einschließlich benutzerdefiniertem Themeneditor
	• Verschiedene Eingabemöglichkeiten (Nummernblock, Popup, Tastatur usw.)
	• Zwei Listen von 'Pencil Marks'
…und vieles mehr.

Weitere Informationen zum Spiel oder wie Ideen oder Fehler gemeldet werden können, finden sie auf der Projekt-Homepage: http://opensudoku.moire.org.
